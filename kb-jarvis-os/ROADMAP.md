# KB Jarvis OS v11 Engineering Roadmap

## Milestone 1 — Native foundation

- Native Windows EXE
- Futuristic animated dashboard
- Permanent KB identity
- Skill registry
- Safe lifecycle intents
- Native SendInput
- Notepad write/save/open verification

## Milestone 2 — Browser and WhatsApp

- Embedded localhost WebSocket bridge
- Auto-reconnecting Chrome extension
- Current-chat inspection
- Exact draft verification
- One-time send confirmation
- Outgoing message verification
- Contact search and disambiguation
- Multiple recipients
- Documents, images, videos and captions

## Milestone 3 — Desktop intelligence

- Existing editor focus and typing
- UI Automation bridge
- Native screenshots
- DPI and multiple-monitor handling
- Keyboard, visual and semantic recovery
- File Explorer and common desktop applications

## Milestone 4 — Teach Mode

- Record demonstrated actions
- Save semantic targets and visual anchors
- Parameterize demonstrations into reusable skills
- Store success and failure scores
- Retry previously successful strategies first

## Milestone 5 — Advanced operators

- ChatGPT complex editor
- WordPress and Elementor
- Instagram messaging and publishing preparation
- VS Code build/test/fix loop
- Persistent task and project memory
